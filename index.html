🔔 Com funcionen els avisos?

L'agenda pot mostrar notificacions quan està oberta i el navegador les permet. Una pàgina web estàtica no pot garantir avisos exactes quan el navegador o el mòbil tanquen l'agenda. Per tenir avisos fiables en segon pla caldrà afegir notificacions push amb un servei compatible i configurar-lo. No donis per fet que els avisos ja funcionen amb l'agenda tancada.
